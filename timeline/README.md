# BibleBucket Interactive Bible Timeline

A dependency-free static experience at <https://biblebucket.net/timeline/>. The homepage links to this section. Existing games, comics, index, and mysteries are left intact.

## Views

- **The story:** seven eras, searchable entries, Enoch/Jubilees filter, guided trails, browser-local saved entries, shareable URL fragments.
- **Kings & prophets:** approximate BCE year lens, parallel kingdoms, ruler bars and a text succession list, broad prophet context windows.
- **Family trees:** five selected genealogies, relationship legend, zoom/scroll, keyboard-selectable people and a text alternative.
- **The atlas:** local Natural Earth basemap, place selector and keyboard-accessible pins, source-aware uncertainty notes, linked stories.
- **Reading room:** on-demand local text files, chapter navigation, referenced verse highlighting, edition attribution, source links, and error recovery.

## Files

- `index.html`, `styles.css`, `app.js`: runtime; no build framework or service required.
- `data.json`: curated entities and connections; generated by `tools/build_data.py`.
- `texts/*.json`: public-domain reading texts; generated by `tools/build_sources.py`.
- `sources.html` and `SOURCES.md`: visible coverage, chronology, licensing, and source notes.
- `assets/story-world.svg`: original art; `assets/land.json`: local projected land shapes.
- `tools/check_data.mjs`: reference, genealogy, path, and integrity checks.

Run `python3 timeline/tools/build_data.py` after a content change, then `node timeline/tools/check_data.mjs` and `node --check timeline/app.js` from the repository root. Serve the **existing checkout** with any static HTTP server; do not create a separate site copy.

The optional `tools/check_browser.cjs` uses Playwright Core and an installed Chromium. It renders these files with network access blocked and supplies local data in memory; it does not navigate to loopback endpoints. This is useful where browser tooling disallows localhost previews. Real deployment verification must still load the public site and verify its asset requests.

## Deliberate boundaries

The requested exact 88-book Ethiopian edition has not been identified. Enoch and Jubilees are fully integrated, but the UI does not claim the reader is a complete Ethiopian Bible. Early chronology is narrative rather than fabricated BCE dates. Maps are orientation aids, not reconstructed routes. See `SOURCES.md` before expanding the material.
