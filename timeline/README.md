# BibleBucket Interactive Bible Timeline

A dependency-free static experience at <https://biblebucket.net/timeline/>. The homepage links to this section. Existing games, comics, index, and mysteries are left intact.

## Views

- **The story:** fourteen eras, with the original seven unchanged and a Jesus-centered continuation through Revelation; searchable entries, Enoch/Jubilees filter, guided trails, browser-local saved entries, shareable URL fragments.
- **Kings & prophets:** approximate BCE year lens, parallel kingdoms, ruler bars and a text succession list, broad prophet context windows.
- **Family trees:** six selected genealogies, including a Matthew-based path to Jesus with a distinct Joseph household/guardian relationship, relationship legend, zoom/scroll, keyboard-selectable people and a text alternative.
- **The atlas:** original heartlands map plus a wider Mediterranean map reaching Rome; local Natural Earth basemaps, place selector and keyboard-accessible pins, source-aware uncertainty notes, linked stories.
- **Reading room:** on-demand local text files, chapter navigation, referenced verse highlighting, edition attribution, source links, and error recovery.

## Files

- `index.html`, `styles.css`, `app.js`: runtime; no build framework or service required.
- `data.json`: curated entities and connections; generated by `tools/build_data.py`; additive continuation curated in `tools/new_testament.py`.
- `texts/*.json`: public-domain reading texts; generated by `tools/build_sources.py`.
- `sources.html` and `SOURCES.md`: visible coverage, chronology, licensing, and source notes.
- `assets/story-world.svg`: original art (unchanged); `assets/land.json`: original heartlands; `assets/mediterranean-land.json`: the same source projected for the wider map.
- `tools/check_data.mjs`: reference, genealogy, path, and integrity checks.

Run `python3 timeline/tools/build_data.py` after a content change, then `node timeline/tools/check_data.mjs`, `node timeline/tools/check_expansion.mjs`, and `node --check timeline/app.js` from the repository root. Serve the **existing checkout** with any static HTTP server; do not create a separate site copy.

The optional `tools/check_browser.cjs` uses Playwright Core and an installed Chromium. It renders these files with network access blocked and supplies local data in memory; it does not navigate to loopback endpoints. This is useful where browser tooling disallows localhost previews. Real deployment verification must still load the public site and verify its asset requests.

## Deliberate boundaries

The requested exact 88-book Ethiopian edition has not been identified. Enoch and Jubilees are fully integrated, but the UI does not claim the reader is a complete Ethiopian Bible. Early chronology is narrative rather than fabricated BCE dates. Maps are orientation aids, not reconstructed routes. See `SOURCES.md` before expanding the material.

## Creation-to-new-creation continuation

The expansion adds 159 entries (347 total), seven eras (14 total), 36 places (70 total), nine journeys (15 total), one selected family tree (six total), and 27 Scripture-echo panels. All 27 New Testament books are cited, but this is curated coverage, not an entry for every passage. The first-release 188 entries, seven eras, 34 places, five families, six trails, and 17 prophet windows are protected by hashes in `tools/check_expansion.mjs`.

- Jesus has three narrative eras: arrival, ministry, and cross/resurrection. The landing-page gateway and guided journey provide direct entry without moving the default start away from Genesis.
- Revelation has a symbol index, seven separate church messages, and labeled text-to-text echoes. Its vision sequence is not assigned calendar dates. Disputed interpretations remain identified as such.
- BC/AD and BCE/CE are explained on the source page; the existing kings chart remains an ancient Israel/Judah view, not a new Roman or eschatological chronology.
- The original map remains available. Western/northern places automatically open the wider Mediterranean frame; an explicit map selector allows switching. Dashed lines are associations, not asserted routes.
- Rebuild the wider map with `python3 timeline/tools/build_mediterranean.py /path/to/land.geojson`. The script verifies the original source hash and does not touch reading files or the original map.
- Browser-local saved entries and original entry IDs remain compatible. No accounts, external runtime libraries, or services were added.
